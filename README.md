# 더 나은 메모장 (Extended Notepad)

하나의 창에서 입력 공간(pane)을 여러 개로 나눠 쓰는 Windows 메모장.
분할 기능을 뺀 나머지는 Windows 10 메모장과 똑같이 동작하는 것을 목표로 한다.

- 대상: Windows 10 / 11 (x64)
- 설치 불필요. 실행 파일 하나만 있으면 된다.
- 창 하나 = 문서 하나. 여러 문서는 창(프로세스)을 여러 개 띄운다.

## 다운로드

### ⬇ [ExtendedNotepad.exe 내려받기](https://github.com/Hyuni02/ExtendedNotepad/releases/latest/download/ExtendedNotepad.exe)

[모든 릴리스 보기](https://github.com/Hyuni02/ExtendedNotepad/releases)

내려받은 파일을 그대로 실행하면 된다. 설치 과정도, 별도 런타임도 필요 없다.
`.etxt`를 탐색기에서 더블클릭해 열고 싶다면 [`.etxt` 파일 연결](#etxt-파일-연결)을 참고한다.

## 빌드

Visual Studio 2022(C++ 데스크톱 워크로드)가 설치돼 있어야 한다.

```bat
build.bat
```

자체 검증까지 같이 돌리려면:

```bat
build.bat test
```

`test`를 주면 같은 `main.cpp`를 `/DSELFTEST`로 한 번 더 빌드해 콘솔 실행 파일을 만들고
바로 실행한다. 트리 배치, 경로, undo/redo, 타이핑 묶음 병합, `.etxt` 왕복, 인코딩,
찾기/바꾸기를 `assert`로 검사하며 `selftest ok`가 찍히면 통과다.

## 입력 공간 (핵심 기능)

| 기능 | 단축키 |
|---|---|
| 좌우 분할 | `Ctrl+R` |
| 상하 분할 | `Ctrl+T` |
| 현재 공간 닫기 | `Ctrl+W` |
| 현재 공간 단독 저장 | `Ctrl+Alt+S` |
| 다음 공간으로 | `Ctrl+Tab` |
| 이전 공간으로 | `Ctrl+Shift+Tab` |

- 분할하면 포커스가 있던 공간이 반으로 갈리고 **오른쪽/아래쪽**에 빈 공간이 새로 생긴다.
  포커스는 새 공간으로 옮겨간다.
- 닫으면 남은 공간이 그 자리를 채운다. 공간이 하나뿐일 때 `Ctrl+W`를 누르면 창이 닫히며,
  저장하지 않은 변경이 있으면 저장할지 묻는다.
- 공간 사이 경계선을 마우스로 끌면 크기를 조절할 수 있다. 공간 개수와 최소 크기에 제한은 없다.
- 공간 순서는 **왼쪽 위에서 오른쪽 아래** 순이다. `Ctrl+Tab` 순회, `.etxt` 저장 순서,
  `.txt`로 내보낼 때 이어 붙이는 순서가 모두 이 순서를 따른다.
- 지금 어느 공간에 입력되는지는 **캐럿 깜빡임**으로 구분한다. 별도의 테두리 표시는 없다.
- 위 네 가지는 공간 안에서 **마우스 오른쪽 버튼**을 눌러도 나온다.

### 현재 공간 단독 저장

"다른 이름으로 저장" 창이 떠서 **포커스가 있는 공간의 내용만** 그 이름으로 저장한다.
내보내기일 뿐이라 창 제목도, 수정 상태(`*`)도 바뀌지 않고, 이후 `Ctrl+S`는 원래 파일에 저장한다.

## 파일

| 기능 | 단축키 |
|---|---|
| 새로 만들기 | `Ctrl+N` |
| 새 창 | `Ctrl+Shift+N` |
| 열기 | `Ctrl+O` |
| 저장 | `Ctrl+S` |
| 다른 이름으로 저장 | `Ctrl+Shift+S` |
| 인쇄 | `Ctrl+P` |

페이지 설정(여백)은 `파일 > 페이지 설정`에 있다. 인쇄하면 모든 공간의 내용이
공간 순서대로 이어져 출력된다.

### `.etxt` — 기본 저장 형식

공간의 배치와 공간별 텍스트를 함께 저장한다. 구조는 이렇다.

```
ETXT1
{"root":{"d":"V","r":0.3000,"a":{"p":0},"b":{"d":"H","r":0.5000,"a":{"p":1},"b":{"p":2}}},"focus":0,"wrap":true}
<NUL>PANE 0
(0번 공간 내용)<NUL>PANE 1
(1번 공간 내용)...
```

첫 줄은 형식 버전, 둘째 줄은 배치 트리(JSON 한 줄), 그 뒤로 공간별 본문이 이어진다.
`d`는 분할 방향(`V` 좌우 / `H` 상하), `r`은 경계선 위치(0~1), `p`는 공간 번호다.
본문은 escape 없이 그대로 들어가므로 파싱이 사실상 복사뿐이고, 다른 편집기로 열어도 내용은 읽힌다.

### `.txt` — 기존 메모장과 호환

- `.txt`를 열면 공간 하나에 전체 텍스트가 들어간다.
- `.txt`로 저장하면 공간 내용을 순서대로 이어 붙인다. **배치 정보는 사라지며**,
  공간이 둘 이상이면 저장 전에 경고한다.

### 인코딩 / 줄바꿈

기본은 UTF-8이고 `파일 > 인코딩`에서 UTF-8 / UTF-8(BOM) / UTF-16 LE / ANSI 중 고를 수 있다.
파일을 열 때 BOM이 있으면 BOM을 따르고, 없으면 현재 설정으로 해석한다.
줄바꿈은 Windows 10 메모장 기준으로 **CRLF**만 줄바꿈으로 본다. 단독 LF는 줄을 나누지 않는다.

### 실행 취소는 공간까지 되돌린다

글자 편집뿐 아니라 **분할하고 닫은 것도 같은 순서로 되돌아간다.**
닫은 공간을 `Ctrl+Z`로 되살리면 그 안에 있던 내용까지 그대로 돌아온다.

연속으로 친 글자는 한 덩어리로 묶여 한 번에 취소된다. 줄바꿈에서 묶음이 끊기므로
되돌리기 단위는 대체로 줄 단위가 된다. 한글 입력 중 글자가 완성되어 가는 과정도
한 덩어리로 묶인다.

### 찾기 / 바꾸기

기본은 포커스가 있는 공간만 대상으로 한다. 대화상자의 **"모든 공간에서 찾기"**를 켜면
공간 순서대로 넘어가며 찾는다. "되돌아 찾기"를 켜면 끝에 닿았을 때 처음부터 한 바퀴 더 돈다.

"모두 바꾸기"는 공간마다 한 번에 치환하므로, 수백 개를 바꿔도 `Ctrl+Z` **한 번**이면 되돌아간다.

> `Ctrl+G`(줄 이동)는 자동 줄 바꿈이 켜져 있으면 비활성이다. 줄 바꿈 중에는 화면상의 줄과
> 실제 줄 번호가 달라지기 때문이며, Windows 메모장도 같다.

## 서식 / 보기

| 기능 | 단축키 |
|---|---|
| 확대 | `Ctrl` + `+` |
| 축소 | `Ctrl` + `-` |
| 기본 크기 복원 | `Ctrl+0` |
| 확대/축소 | `Ctrl` + 마우스 휠 |

- 자동 줄 바꿈, 글꼴, 확대 배율은 **창 전체**에 적용된다. 공간별로 따로 두지 않는다.
- 확대 범위는 10%~500%.
- 상태 표시줄에 줄/열, 확대 배율, 줄 끝 형식, 인코딩이 표시된다. `보기` 메뉴에서 끌 수 있다.
- 스크롤바는 내용이 공간을 넘어갈 때만 나타난다.

## 설정

`서식 > 설정`에서 기본 인코딩, 글꼴, 자동 줄 바꿈 기본값을 바꾼다.
설정은 `%APPDATA%\ExtendedNotepad\settings.ini`에 저장된다.

창을 닫을 때 다음도 함께 저장해서 다시 켤 때 그대로 되돌린다.

- **창의 위치와 크기.** 최대화한 채로 닫았다면 최대화된 채로 뜨고, 그 상태에서 복원하면
  최대화하기 전 크기로 돌아간다.
- **확대 배율.** `Ctrl` + `+`/`-`나 `Ctrl` + 휠로 맞춰둔 글자 크기가 그대로 유지된다.
- 자동 줄 바꿈, 상태 표시줄 표시 여부

> 저장된 자리가 어느 모니터에도 걸치지 않으면(화면 구성이 바뀐 경우) 무시하고 기본 위치에 띄운다.

## `.etxt` 파일 연결

탐색기에서 `.etxt`를 더블클릭해 열고 싶다면 등록한다. `HKCU`만 건드리므로 관리자 권한이 필요 없다.

```bat
powershell -ExecutionPolicy Bypass -File register.ps1
```

해제는 이렇게 한다.

```bat
powershell -ExecutionPolicy Bypass -File register.ps1 -Unregister
```

### 설계 메모

- **Win32 + 네이티브 EDIT 컨트롤.** 공간 하나가 EDIT 컨트롤 하나다. 텍스트 편집, IME,
  캐럿, 선택, 스크롤, 접근성은 OS가 이미 해주는 일이라 직접 만들지 않았다.
  시작 300ms, 메모리 30MB 목표를 .NET이나 Electron으로는 맞출 수 없다.
- **배치는 이진 트리.** 분할은 잎(공간)을 가지(분할선)로 바꾸는 것이고, 닫기는 가지를
  형제로 되돌리는 것이다. 되돌리기는 명령을 기록할 때의 트리 경로를 그대로 쓴다.
- **글자 편집은 EDIT 컨트롤을 가로채 기록한다.** 편집 전후로 닿을 수 있는 줄 범위만 읽어
  공통 부분을 잘라내므로, 기록 비용이 문서 크기와 무관하다.

## 아직 없는 것

- 인쇄 머리글/바닥글, 페이지 번호
- 파일을 창에 끌어다 놓아 열기
- 탭, 자동 저장, 세션 복원, 플러그인 (만들지 않기로 한 것들)
- 문서가 256KB를 넘으면 가로 스크롤바는 자동으로 숨지 않는다 (가장 긴 줄을 재는 비용 때문)
- 지정한 입력 경로 밖에서 텍스트가 바뀌면 그 편집은 되돌리기에 기록되지 않는다
